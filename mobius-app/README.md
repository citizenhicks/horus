# möbius App

The möbius app is one SwiftUI client for iPhone and iPad. It pairs with a local
or remote `mobius-gateway`; no agent runtime or
provider credential lives in the app.

Open [`apple/MobiusApp.xcodeproj`](apple/MobiusApp.xcodeproj) and run the shared
`MobiusApp` scheme. See the [iOS client guide](apple/README.md) for supported
platforms, pairing, and command-line verification.
