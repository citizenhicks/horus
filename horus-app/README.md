# Horus App

The Horus app is one shared SwiftUI client for macOS, iPhone, and iPad. Every
platform pairs with a local or remote `horus-gateway`; no agent runtime or
provider credential lives in the app.

Open [`apple/HorusApp.xcodeproj`](apple/HorusApp.xcodeproj) and run the shared
`HorusApp` scheme. See the [Apple client guide](apple/README.md) for supported
platforms, pairing, and command-line verification.
