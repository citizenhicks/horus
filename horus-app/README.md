# Horus App

The Horus app is one SwiftUI client for iPhone and iPad. It pairs with a local
or remote `horus-gateway`; no agent runtime or
provider credential lives in the app.

Open [`apple/HorusApp.xcodeproj`](apple/HorusApp.xcodeproj) and run the shared
`HorusApp` scheme. See the [iOS client guide](apple/README.md) for supported
platforms, pairing, and command-line verification.
